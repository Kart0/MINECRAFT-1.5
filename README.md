# 🌍 Language Collaboration

Thank you for your interest in helping improve the translations of this project.

This modpack includes support for a large number of languages. While every translation has been carefully prepared and reviewed where possible, some languages may still contain grammatical issues, awkward wording, inconsistent terminology, or phrases that may not sound natural to native speakers.

This branch contains the original English language file (`en_us.json`), which serves as the reference for all translations.

## How You Can Help

If you are a native speaker (or highly proficient) in one of the supported languages, your contributions are highly appreciated.

You can help by:

* Correcting grammar, spelling, and punctuation.
* Improving sentence structure and readability.
* Adjusting terminology to better match common usage in your language.
* Making translations sound more natural and consistent.
* Reporting missing, incorrect, or confusing translations.

## Getting Started

This collaboration branch intentionally contains only the reference language file (`en_us.json`).

Contributors are encouraged to use this file as the source reference when reviewing, creating, or improving translations for their language.

[_An optional online tool is also available to assist with the creation and editing of Minecraft language files_](https://kart0.github.io/mc-language-generator/)

After completing your translation work, simply submit your changes through a Pull Request for review.

## Translation Guidelines

* Preserve formatting codes, placeholders, and variables.
* Keep the original meaning of the text.
* Prioritize natural and clear wording over literal translations.
* Maintain consistency with existing Minecraft terminology whenever possible.

## Contributor Recognition

All translation contributors will be credited on the modpack's official page when the project is publicly released.

Translation improvements will continue to be accepted after release, and all future contributors whose work is incorporated into the project will also receive proper credit.

Whether you improve a single sentence or help review an entire language file, your contribution will be recognized and greatly appreciated.

## Thank You

Localization is an ongoing effort, and community feedback plays an important role in making the modpack accessible to players around the world.

Thank you for helping improve the experience for everyone. Every contribution, no matter how small, makes a difference.

Happy translating!
